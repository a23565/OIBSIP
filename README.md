## 🌟 Task Highlights & Features

### 1. [Landing Page — AuraFlow](./WebDev-L1-LandingPage)
- **Objective:** Visually polished, static SaaS landing page for an AI cloud orchestration platform.
- **Key Features:**
  - Sticky glassmorphic navigation with 5 section links and CTA buttons.
  - High-impact hero section with live CSS dashboard mockup and trust badges.
  - 6-feature grid with custom SVG iconography and hover micro-interactions.
  - 3-step workflow pipeline breakdown with platform metrics ticker (99.99% SLA, 4.2B+ executions).
  - Customer testimonial cards, 3-tier pricing table with popular badge, and FAQ accordion.
  - Pure CSS responsive hamburger drawer menu (zero JS required).

### 2. [Personal Portfolio & Digital Resume](./WebDev-L1-PersonalPortfolio)
- **Objective:** Personal digital portfolio showcasing technical proficiencies, projects, and contact channels.
- **Key Features:**
  - Dynamic Dark and Light mode theme toggle with localStorage persistence.
  - Sticky header with active scroll-spy section highlighting.
  - Categorized technical skills (Frontend, Backend, Tools) with animated percentage progress bars.
  - Filterable project showcase cards (All, Frontend, Full-Stack) with preview mockups.
  - Career journey roadmap and timeline.
  - Client-side validated contact form with real-time feedback and success banner.

### 3. [Temperature Converter — ThermoPulse](./WebDev-L1-TemperatureConverter)
- **Objective:** Interactive calculation tool converting temperatures with thermodynamic safety checks.
- **Key Features:**
  - Real-time conversion across **Celsius (°C)**, **Fahrenheit (°F)**, **Kelvin (K)**, and **Rankine (°R)**.
  - Simultaneous multi-unit matrix display showing all converted values at a glance.
  - **Absolute Zero edge-case violation alert** with scientific context on the Third Law of Thermodynamics.
  - Dynamic thermal gauge bar shifting from cryogenic cyan to room-temp green to boiling purple.
  - Step-by-step mathematical calculation and formula breakdown.
  - Quick presets (Absolute Zero, Freezing, Room Temp, Body Temp, Boiling) and session history log.

## ⚡ Quick Start: Running Projects Locally

You can run any of the three completed projects directly in any modern browser without external dependencies:

```bash
# Clone the repository
git clone https://github.com/a23565/OIBSIP.git
cd OIBSIP

# To view Task 1 (Landing Page)
cd WebDev-L1-LandingPage
# Open index.html in your browser or run:
python -m http.server 8080

# To view Task 2 (Personal Portfolio)
cd ../WebDev-L1-PersonalPortfolio
python -m http.server 8081

# To view Task 3 (Temperature Converter)
cd ../WebDev-L1-TemperatureConverter
python -m http.server 8082
```
