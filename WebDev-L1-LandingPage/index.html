COMMON QUESTIONS

Frequently Asked Questions

How does AuraFlow integrate with my existing tech stack? ↓

AuraFlow connects seamlessly via standardized REST APIs, Webhooks, GraphQL, and SDKs available for Python, Node.js, Go, and Java. You can trigger flows from GitHub actions, database triggers, Kafka streams, or cloud events with zero custom connector coding.

Can I export and self-host my workflows? ↓

Yes! Every workflow is stored in an open declarative YAML format. Enterprise subscribers can run the AuraFlow execution daemon inside their private Kubernetes clusters or air-gapped on-premises data centers.

What happens if my execution volume exceeds the monthly quota? ↓

Your workflows will never experience downtime or hard blocks. We provide a grace threshold and notify you well in advance, allowing you to upgrade smoothly or pay transparent per-unit overage rates.
